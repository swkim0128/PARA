# Obsidian

로컬 마크다운 파일을 양방향 wikilink·그래프 뷰로 다루는 노트 IDE. 본 PARA 볼트의 메인 편집·시각화 환경이다.

## 본 위키와의 역할

- `03.Resources/Wiki/` 하위 페이지는 모두 Obsidian으로 열어 wikilink·Graph View로 토폴로지를 확인.
- [[Obsidian Web Clipper]] 확장과 함께 사용하면 웹 글을 Clippings/_Inbox로 즉시 수집 가능.
- Dataview 플러그인으로 frontmatter(`status`, `tags`, `para` 등) 쿼리.
- obsidian-git 플러그인으로 자동 백업 (30분 주기).

## 활용 플러그인 (본 볼트 기준)

- **obsidian-git**: Git 저장소로 자동 백업
- **dataview**: frontmatter 쿼리
- **calendar**: 일일 노트 달력 뷰
- **templater-obsidian**: 노트 템플릿
- **excalidraw**: 다이어그램
- **obsidian-linter**: 마크다운 포맷팅
