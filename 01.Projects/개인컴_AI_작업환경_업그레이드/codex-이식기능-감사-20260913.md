## 사용자 요청과 재개 지점

Claude Code에서 Codex로 이식한 스킬·스크립트·훅·에이전트의 목록과 실동작 여부를 조사했다. 사용자는 이 Codex 대화를 종료하고 Claude Code를 다시 실행해 분석 결과에 따라 설정을 업데이트하기로 했다. 이번 감사는 읽기 전용이며 아래 결함은 아직 수정하지 않았다.

**첫 작업:** `vibe-ai-config`에서 모델 프로필 설치 형식을 현재 Codex CLI에 맞게 수정한다. 정본과 기존 사용자 변경을 먼저 확인하고 격리 worktree에서 진행한다. 그다음 위임 기본값, 에이전트 호출, Codex 훅 계약 순서로 검증한다.

## 우선순위 1 — 프로필 실행 오류 (재현됨)

- 정본: `vibe-ai-config/codex/model-profiles.toml:3`, 설치기 `install.sh:310` 및 `:487` 부근.
- 설치기가 `~/.codex/config.toml`에 구형 `[profiles.routine]`, `[profiles.review]`, `[profiles.deep]`를 삽입한다.
- 현재 CLI는 `~/.codex/<name>.config.toml`을 요구하며 같은 이름의 구형 테이블이 있으면 실행을 거부한다. 별도 세 파일은 이미 존재하고 값도 맞지만, 구형 테이블이 실행을 막는다.
- 아래 명령은 각각 종료 코드 1을 반환했다. 모델 추론을 요청하지 않는 구성 로드 검사다.

```bash
codex --profile routine mcp list
codex --profile review mcp list
codex --profile deep mcp list
```

오류 핵심: `cannot be used while ... config.toml contains legacy ... [profiles.routine] config; move those settings into .../routine.config.toml and remove the legacy profile selector/table`.

수정 목표: 정본이 별도 프로필 파일을 배포하도록 변경하고, 기존 관리 블록의 구형 프로필을 사용자 추가 키 보존과 함께 이관한다. 설치 2회 멱등성·기본 모델·프로젝트 trust·hooks.state 보존을 검증한 뒤 위 실제 로드 명령 3개를 통과시킨다. `--help`, TOML 파싱, 기본 `doctor` 성공만으로 완료 판정하지 않는다.

| 프로필 | 모델 | 추론 강도 |
|---|---|---|
| routine | gpt-5.6-luna | low |
| review | gpt-5.6-sol | medium |
| deep | gpt-6-astra | high |

**이전 보고 정정:** `c99a80d` 설치 변경과 라이브 배포는 실행됐으나, 프로필 사용 가능 여부를 입증하지 못했다. 이전의 “프로필 배포·검증 완료” 판정은 철회한다.
