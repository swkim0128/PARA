## 2. 일정관리 (R1~R6)

- **R1 캘린더 MCP 전환**: `gws-cal-to-notion` 이벤트 조회를 Google Calendar MCP 우선으로 개편, MCP 미가용 환경은 gws CLI 폴백. 슬롯 반영은 Phase 1의 slot-edit-protocol(append 기본) 준수.
- **R5 예정/완료 표기**: 슬롯 항목 표기 규칙 신설 — 예정 항목은 `(예정)` 접미, 수행 확인 시 접미 제거. 도메인 문서(04.일정.md)에 정의.
- **R6 일요일 회고**: notion-suite `auto-retrospect` 훅을 요일 인지형으로 확장 — 일요일 세션이면 `/notion weekly`(주간 루틴: 정리→KPT 회고→차주 계획) 실행을 우선 권고. 완전 자동 실행은 노트북 상시 구동이 아니므로 반자동(권고형)으로 확정.
- **04.일정.md 신설**: 슬롯 시각표(평일/주말)·예정/완료 표기·Week List 업무/개인 분류 규칙을 담는 도메인 정본. vibe-ai-config `slot-edit-protocol.md`는 노션 편집 메커니즘(스냅샷·라인 카운트·selection 규칙)만 유지하고 시각표는 이 문서를 인용.

## 3. 예산관리 (B1~B4)

- **B1 Wish List**: 월 Budget 페이지에 `## Wish List` 섹션(표: 품목 | 예상가 | 등록일 | 상태(대기/구매완료/대체됨) | 매핑 지출). 월 이월: 새 달 페이지 생성 시 미구매 항목 복사.
- **B2 뱅크샐러드 import**: 고정 드롭 폴더 **`~/Documents/banksalad/`** (git 추적 볼트 밖 — 금융 데이터를 원격 push 대상에 두지 않음). 스킬이 폴더 내 최신 파일(xlsx/csv)을 파싱 → 지출 도메인 모델(날짜·금액·가맹점·카테고리) → 노션 기록. **중복 방지 키 = 날짜+금액+가맹점** (이미 기록된 조합은 skip, 재업로드 안전). 기존 대화 입력 병행 유지.
- **B3 매핑/대체**: import 시 각 지출을 wish list 대기 항목과 대조(품목명 유사도) → 일치: 해당 항목 구매완료 + 지출 연결 / 유사 품목: 항목을 실구매 품목으로 교체 후 구매완료(상태=대체됨) / 모호하면 후보 제시.
- **B4 월말 정리**: `/notion budget close [YYYY-MM]` 흐름 신설 — 카테고리별 합계·예산 대비 증감·wish list 소화율을 요약 블록으로 페이지 컨텐트에 append. 합계는 지출 내역 재집계로 검산(diagnosis #10 검산 규칙 겸용).
- **카테고리 7종 확정**(식비/교통/문화/의료/공과금/의류·생활/기타) — 6/7 자기모순 해소, 도메인 문서(03.예산.md)가 정본.

## 4. 식단관리 (D1~D2)

- **D1 재고**: SoT = **Ingredients 마스터 DB의 재고 상태 속성**('보유 중' 여부). 구매→보유 중, 소진("다 먹었어")→해제. 주간 Diet 페이지 relation은 파생 뷰(참조용). n8n 주간 생성 템플릿은 보유 중 항목을 relation으로 채우도록 후속 조정(연동 포인트로 기록만, n8n 수정은 본 프로젝트 범위 밖).
- **D2 요일×끼니**: Diet 페이지 본문에 표 신설 — 행=점심/저녁, 열=일~토. 셀 항목은 실적(그대로)/예정(`(예정)` 접미, 일정과 동일 규칙). 슬롯 편집과 동일하게 편집 전 스냅샷·전체 셀 replace 규율 적용.
- **페이지 부재 폴백**: n8n 미생성 시 스킬이 표준 템플릿(제목 규칙 `[week XX] @YYYY/MM/DD → YYYY/MM/DD 식단` + 요일×끼니 표)으로 직접 생성 (diagnosis #9 해소).
- **diet → budget 역방향 분기**: 식재료+가격 동시 언급 시 diet 스킬에서도 budget 분기 명시 (diagnosis #8 해소).
