# 이직 준비 — 이력·경험 정리

- **노션**: [PRO-133](https://app.notion.com/p/3f4a25196d348148a22ef2c7e7d84af9)
- **상태**: Backlog (2026-10-09 사이드 프로젝트로 등록만 — 아직 착수 안 함)
- **우선순위**: 중간
- **태그**: 개인 · 사이드 프로젝트 (Area: 개인 사이드 프로젝트)

## 목표

이직 준비를 위해 현재까지의 이력과 프로젝트·업무 경험을 정리해, 이력서·경력기술서로 바로 옮길 수 있는 상태로 만든다.

## ⚠️ 이 폴더에는 포인터만 둔다

이 볼트는 **공개 저장소**다. 이력·경력 내용에는 개인정보와 회사 내부 정보가 들어가므로 **본문은 노션 PRO-133(비공개)에 쓰고**, 여기에는 진행 상태와 노션 링크만 남긴다. 회사 코드·내부 문서는 볼트로 가져오지 않는다.

## 착수 시 다음 행동

1. 노션 Status 를 `Planning` 으로 바꾼다.
2. 노션 Projects DB 의 `다나와` 태그 항목 50건(과거 업무 경험 기록, 읽기 전용)과 Area 「개발 경험 정리」를 훑어 경험 후보를 뽑는다.
3. 프로젝트별로 문제 → 한 일 → 결과(수치) 형태로 정리한다.
