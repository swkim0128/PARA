# 이직 준비 — 지원 기업 조사·정리

- **노션**: [PRO-134](https://app.notion.com/p/3f4a25196d3481fb9347fd9e7cc48a59)
- **상태**: Backlog (2026-10-09 사이드 프로젝트로 등록만 — 아직 착수 안 함)
- **우선순위**: 중간
- **태그**: 개인 · 사이드 프로젝트 (Area: 개인 사이드 프로젝트)
- **짝 프로젝트**: [[이직_준비_이력_경험_정리/README|이직 준비 — 이력·경험 정리]] (PRO-133)

## 목표

이직하고 싶은 기업 목록을 조사해, 지원 우선순위와 기업별 준비 사항을 정리한다. 기업이 요구하는 역량을 PRO-133 의 경험 정리와 대조해 지원 서류를 맞춘다.

## ⚠️ 이 폴더에는 포인터만 둔다

이 볼트는 **공개 저장소**다. 지원 현황·연봉 등은 개인 정보이므로 **본문은 노션 PRO-134(비공개)에 쓰고**, 여기에는 진행 상태와 노션 링크만 남긴다.

## 착수 시 다음 행동

1. 노션 Status 를 `Planning` 으로 바꾼다.
2. 기업 선택 기준(필수/선호 — 직무·기술 스택·규모·연봉·근무 방식)을 확정한다.
3. 후보 목록을 둘 곳(노션 페이지 표 또는 지원 상태 추적용 DB)을 정하고 1차 조사를 한다.
