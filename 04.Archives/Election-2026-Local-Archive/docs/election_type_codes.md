## 검증 방법
1. `data.go.kr → 마이페이지 → 활용신청 상세보기 → 참고문서` 에서 코드 표 확인
2. 또는 `python -m scripts.fetch_vote_results --sg-id 20260603 --sg-type 3` 호출 후 응답의 `sdName` 값이 시·도지사다운 행정구역(서울특별시, 부산광역시 등)으로 17개 행 정도 반환되는지 확인.

### 미반영 데이터 메모
- 2026-06-13 기준, sgId=`20260603` (제9회 지방선거)는 두 API(`WinnerInfoInqireService2`, `VoteXmntckInfoInqireService2`)에서 모두 `INFO-03` ("데이터 정보가 없습니다") 반환.
- 선거 후 OpenAPI 반영까지 통상 2~3주 소요 (선관위 결과 확정 → 데이터 검증 → 공공데이터포털 동기화).
- 일별 재시도 권장.
