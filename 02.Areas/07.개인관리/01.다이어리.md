# 📔 다이어리 관리 SOP (툴 무관) — 저장소: 노션(어댑터)

> 공통 규약은 [README](README.md), 노션 전제 조건·절차는 [어댑터: 노션](adapters/notion/README.md) 참조. 대상: 일간 다이어리 페이지 (DB ID 미고정 — 동적 검색).

## 절차

1. 오늘 날짜 계산 `YYYY-MM-DD`
2. `notion-search` 키워드 순차 시도: `{YYYY-MM-DD}` → `일기 {YYYY-MM-DD}` → `Diary {YYYY-MM-DD}` → `다이어리`
   - 단일 결과 → 채택 / 다중 → 사용자 선택 / **0건 → 생성 금지, 보고 후 중단** ([README](README.md) 메타 룰 6)
3. `notion-fetch` 로 페이지 구조 확인
4. 사용자 입력 분류: **감정 / 주요 사건 / 하이라이트 / 자유 메모**
5. `notion-update-page` 로 본문 **하단 append** (시각 stamp 포함)
6. 결과 보고 (공통 템플릿)

## 신규 페이지 생성 규칙

> 🚫 **에이전트는 이 절차를 실행하지 않는다 (2026-08-22).** 페이지 생성은 매주 일요일 n8n 자동화 소관이다. 아래 규격은 n8n 이 만드는 페이지의 **참조 명세**로만 유지한다. 페이지가 없으면 생성하지 말고 사용자에게 보고한다.

- 제목 = `{YYYY-MM-DD}`, 속성: `Date`={today}, `Mood`=(미정)
- 부모 위치는 첫 사용 시 1회만 확인, 이후 동일 위치 재사용
- 본문 템플릿:

```markdown
# {YYYY-MM-DD} ({요일})

## 오늘의 한 줄
> (사용자가 채울 영역)

## 기록

### {HH:MM}
(첫 entry)

---

## 마무리
- 감정 태그:
- 내일 할 일:
```

## 기록 규칙

- **append-only**: 기존 본문 덮어쓰기 금지. 항상 `### {HH:MM}` 시각 헤더 + 본문으로 하단 추가.
- 시각: 기본 현재 시각. "오전에"→`### 10:00`, "저녁에"→`### 19:00` 식 수동 매핑, 모호하면 현재 시각.
- 입력 변환: 키워드만 오면 한 줄 메모로(풀문장 강제 X), 풀문장은 그대로 보존 + 태그 추가, 이미지/링크는 image/bookmark 블록.
- **중복 방지**: 마지막 `### HH:MM` 헤더와 5분 미만 차 + 본문 동일 → 중복으로 간주, 확인 후 생략.
