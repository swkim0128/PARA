# 🍽️ 식단 관리 SOP (툴 무관) — 저장소: 노션(어댑터)

> 공통 규약은 [[README]], 노션 전제 조건·절차는 [어댑터: 노션](adapters/notion/README.md) 참조. 대상 DB: Diet / Ingredients / Foods — **ID는 [ids](adapters/notion/ids.md) 인용** (하드코딩 금지).
>
> **최종 갱신 2026-08-14** — 노션 식단 DB가 2026-08-11·08-14 두 차례 바뀐 것을 반영.

- 주간 페이지 제목: `[week XX] @YYYY/MM/DD → YYYY/MM/DD 식단` (검색: `week {WW} {YYYY} 식단`)
- **주간 페이지는 n8n이 자동 생성** — 부재 시 폴백 생성 규칙(아래) 적용.

## DB 3종과 관계 현황

| DB | 역할 |
|---|---|
| **Diet** | 주간 식단. **주차별 식단의 정본은 페이지 본문의 요일×끼니 표** |
| **Ingredients** | 식재료 마스터. **재고 SoT** |
| **Foods** | 음식 마스터. 음식↔식재료 연결 보유 |

| 관계 | 상태 | 취급 |
|---|---|---|
| Diet ↔ Ingredients | **없음** (2026-08-11 삭제) | 조작하지 않는다 — 재고는 Ingredients 마스터 단일 정본 |
| Diet ↔ Food | 속성은 있으나 **신규로 채우지 않음** (2026-08-14 결정) | 기존 링크는 이력이므로 **삭제하지 않는다** |
| Foods ↔ Ingredient | **유지·확장 대상** | 음식 작업 시 점진적 백필 (아래 규칙) |

Diet의 `Needed Ingredient List`는 Food → Ingredient를 타는 롤업이다. Diet ↔ Food를 채우지 않는 방침에서는 **신규 주차의 값이 비는 것이 정상**이다.

## 재고 관리 (SoT)

- **재고의 단일 정본 = Ingredients 마스터의 `보유 중` 체크박스.**
- **구매** → `보유 중` 체크 / **소진("다 먹었어")** → `보유 중` 해제. 마스터 항목 자체는 삭제하지 않는다.
- **장보기 예정** → `장보기` 체크. 실제 구매 시 `보유 중` 체크와 **함께 `장보기` 해제**.

### Ingredients 속성 규격

| 속성 | 타입 | 규칙 |
|---|---|---|
| `보유 중` | checkbox | 재고 판정 단일 정본 |
| `구분` | select (`소모품` / `상비품`) | **신규 생성 시 필수** |
| `장보기` | checkbox | 구매 예정 표시 |
| `Tag` | multi_select | 아래 분류표로 자동 부여 |
| `Price` | number(원) | 가격 언급 시 기록 (지출은 [[03.예산]]으로도 분기) |

**`구분`을 빠뜨리면 「소모품 (보유 우선)」 뷰의 `구분=소모품` 필터에 신규 식재료가 나타나지 않는다.** 생성 시 반드시 부여한다.

- `소모품` — 신선·냉장·냉동 등 자주 사고 빨리 쓰는 것 (야채·과일·정육/계란·해산물·우유/유제품 등)
- `상비품` — 오래 두고 쓰는 것 (조미료·소스류·오일·건면·통조림·차 등)

## 요일×끼니 표 (주차별 식단의 정본)

- Diet 주간 페이지 본문 `### 식단` 섹션 아래에 표 1개: **행 = 점심 / 저녁, 열 = 일~토**.
- 셀 항목: 실적은 그대로, **예정(계획)은 `(예정)` 접미** — 수행 확인 시 접미만 제거 ([[04.일정]]의 예정/완료 표기 규칙과 동일).
- **n8n이 만든 페이지에 표가 없고 `### 식단`이 비어 있는 경우가 있다** → 표가 없으면 빈 표를 먼저 삽입한 뒤 기록한다.
- 셀 편집은 **해당 행(점심 또는 저녁) 전체를 replace** — 편집 전 행 원문을 스냅샷으로 보관한다.

## Foods ↔ 식재료 백필

음식을 기록·계획할 때 그 음식의 `Ingredient` 연결이 비어 있으면 **근거가 있을 때만** 채운다.

- 근거 = 음식 페이지 본문의 식재료 섹션, 또는 사용자가 직접 언급한 재료.
- **근거가 없으면 건너뛰고 보고에 1줄 남긴다** — 추측으로 채우지 않는다.
- **외식·배달 메뉴는 시도하지 않는다.**
- **일괄 변환하지 않는다** — 작업하다 마주친 음식만 점진적으로 채운다.

## 페이지 부재 시 폴백 생성

이번 주 페이지가 없으면(n8n 미생성) 직접 생성한다.

- 제목: `[week XX] @YYYY/MM/DD → YYYY/MM/DD 식단` (해당 주 **일요일 → 토요일**, 주차 계산은 ISO 8601)
- 속성: `Date`(주 시작일) · `Year` · `Quarter`
- 본문: `## 주간 식단` → `### 식단`(요일×끼니 빈 표) → `### 식재료`(상온 / 냉장실 / 냉동실 3열)

## 절차

1. 이번 주 Diet 페이지 검색 (`week {WW} {YYYY} 식단`) — 없으면 폴백 생성
2. 입력 분류: **식재료 추가(구매) / 식재료 제거(소진) / 장보기 예정 / 음식 기록(실적·예정)**
3. 각 항목 처리:
   - Ingredients/Foods 마스터에서 검색 → 없으면 신규 생성 (**식재료는 `구분` 필수** + 태그 자동 부여)
   - **식재료**: 마스터의 `보유 중`·`장보기` 갱신 (SoT). *Diet 페이지로의 relation 동기화는 하지 않는다 — 관계가 없다.*
   - **음식**: 요일×끼니 표의 해당 셀에 기록. *Diet ↔ Food relation은 채우지 않는다.* 필요 시 Foods ↔ 식재료 백필.
4. 결과 보고

## 규칙

- **속성 값 갱신과 스키마 변경은 다른 작업이다.** 값 갱신에 스키마 변경 도구를 쓰지 않는다. 속성 자체가 없을 때만 1회성으로 추가하고, 수행 사실을 보고에 명시한다.
- **음식 기록**: 끼니 미지정("먹었어")이면 저녁으로 간주.
- 동일 이름 항목 다수 → 가장 최근 생성 항목 사용. 이름 모호 → 짧게 확인.

## 태그 분류표

- **식재료(Ingredients) 11종**: `국/반찬/메인요리` · `야채` · `정육/계란` · `해산물` · `면` · `소스류` · `오일` · `조미료` · `과일` · `우유/유제품` · `생수/음료/차`
- **음식(Foods) 8종**: `특별한`(외식·특별한 날) · `단백질`(고기·생선·계란) · `빠른`(간단·즉석) · `무거운`(기름·고칼로리) · `주말`(손 많이 가는) · `건강한`(채소·저칼로리) · `양식` · `일식`

## 출력 포맷

```
✅ [week XX] 식단 업데이트 완료
| 구분 | 항목 |
|---|---|
| 식재료 추가 (+N) | ... |
| 식재료 제거 (-N) | ... |
| 장보기 예정 (+N) | ... |
| 음식 기록 (+N) | ... |
```

신규 생성 항목은 이름 뒤 `(신규)` 표시. 백필을 건너뛴 음식이 있으면 1줄로 남긴다.

## 분기

- **식재료 + 가격 동시 언급 → 양방향 필수 분기**: 식재료는 본 SOP, 가격은 [[03.예산]]으로 기록. 식단 요청으로 먼저 접수됐더라도 가격이 언급되면 반드시 예산 기록을 함께 수행한다 (지출 기록 누락 방지).
