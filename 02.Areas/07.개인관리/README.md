# 🧭 개인관리 (일정·예산·식단·다이어리) — 도메인 허브 & 정본 레지스트리 (툴 무관)

> **이 파일이 개인관리 도메인의 도구 무관 정본 레지스트리다.** 기능→수단 매핑은 특정 AI 도구 파일이 아니라 이 README가 진입점 정본이며, 아래 **매핑 레지스트리 표가 이 파일의 중심**이다.
>
> **아키텍처 원칙 — 개인관리가 도메인(상위), 노션은 현재 선택된 저장소 어댑터(하위).**
> 이 폴더의 도메인 문서(`0X.*.md`)가 저장소 중립 규칙의 단일 정본(SoT)이다. 스킬(vibe-ai-config `notion-*`)은 도메인 문서를 인용하고 **저장소 조작 절차(어댑터)만** 자체 보유한다. 스킬 없는 환경은 도메인 문서 + 어댑터 문서로 직접 수행한다. 저장소(노션) 교체 시에도 도메인 규칙 층은 불변 — [adapters/](adapters/notion/README.md) 층만 교체한다.

## 메타 룰 (전 도메인 공통)

1. **append-only**: 기존 본문·관계 배열을 덮어쓰지 않는다. 관계 업데이트는 기존 배열 유지 후 추가.
2. **idempotent**: 중복 기록 방지 (도메인별 중복 판정 기준은 각 SOP 참조).
3. **읽기/변경 의도 구분**: "보여줘/확인/얼마" → 조회만, 변경 금지.
4. **슬롯 시각표·배치·예정/완료 표기** → [[04.일정]] 정본 참조 (평일/주말 시각표, 시각 미상 항목 배치, `(예정)` 접미 규칙).
5. 저장소 전용 주의사항(컬럼 레이아웃 등)은 어댑터 문서 참조.
