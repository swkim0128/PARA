# 🍽️ 노션 식단 SOP (툴 무관)

> 공통 규약·전제 조건은 [README](README.md) 참조.

## 대상 DB (하드코딩 ID)

| DB | ID | 용도 |
|---|---|---|
| Diet | `collection://ed46300e-3f34-4ad5-8319-100810b659b9` | 주간 식단 페이지 |
| Ingredients | `collection://3f8112d6-3518-4d77-b86c-8e481c687d2f` | 식재료 마스터 |
| Foods | `collection://8b14c31d-85b4-411d-a1ed-538222261d09` | 음식 마스터 |

- 주간 페이지 제목: `[week XX] @YYYY/MM/DD → YYYY/MM/DD 식단` (검색: `week {WW} {YYYY} 식단`)
- **주간 페이지는 n8n이 자동 생성** — 없으면 "아직 생성되지 않았습니다 (n8n 자동화 대기)" 안내만 하고 직접 만들지 않는다.

## 절차

1. 이번 주 Diet 페이지 검색 (`week {WW} {YYYY} 식단`)
2. 입력 분류: **식재료 추가 / 식재료 제거 / 음식 기록**
3. 각 항목 처리:
   - `notion-search` 로 Ingredients/Foods 마스터에서 검색 → 없으면 `notion-create-pages` 로 신규 생성 (태그 자동 부여)
   - Diet 주간 페이지의 관계(relation) 배열에 **기존 배열 유지 + append**
4. 결과 보고

## 규칙

- **식재료 제거**: Diet 페이지 관계 배열에서만 제거. 마스터 DB 항목은 삭제하지 않는다.
- **음식 기록**: 끼니 미지정("먹었어")이면 저녁으로 간주.
- 동일 이름 항목 다수 → 가장 최근 생성 항목 사용. 이름 모호 → 짧게 확인.

## 태그 분류표

- **식재료(Ingredients)**: 야채 / 정육·계란 / 해산물 / 국·반찬·메인요리 / 면 / 소스류 / 오일 / 조미료 / 과일 / 우유·유제품 / 생수·음료·차
- **음식(Foods)**: 단백질(고기·생선·계란) / 빠른(간단·즉석) / 건강한(채소·저칼로리) / 무거운(기름·고칼로리) / 주말(손 많이 가는) / 양식 / 일식 / 특별한(외식·특별한 날)

## 출력 포맷

```
✅ [week XX] 식단 업데이트 완료
| 구분 | 항목 |
|---|---|
| 식재료 추가 (+N) | ... |
| 식재료 제거 (-N) | ... |
| 음식 기록 (+N) | ... |
```

신규 생성 항목은 이름 뒤 `(신규)` 표시.

## 분기
