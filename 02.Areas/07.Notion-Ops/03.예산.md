# 💰 노션 예산 SOP (툴 무관)

> 공통 규약·전제 조건은 [README](README.md) 참조. 대상: 월간 예산 페이지 (DB ID 미고정 — 동적 검색).

## 절차

1. 이번 달 계산 `YYYY-MM`
2. `notion-search` 키워드 순차 시도: `{YYYY-MM} 예산` → `Budget {YYYY-MM}` → `예산 {YYYY}년 {M}월` → `가계부`
   - 0건 → 자동 생성 (사용자 확인 후, 제목 `{YYYY-MM} 예산`)
3. `notion-fetch` 로 페이지 + 내부 DB(또는 Budget data source) 구조 확인
4. 입력 파싱: **금액·항목명(필수) / 카테고리(자동 추론) / 결제 수단(선택) / 날짜(기본 오늘)**
5. `notion-create-pages` 또는 `notion-update-data-source` 로 지출 row 추가
6. 합계 갱신(본문 테이블 또는 rollup) → 잔액·경고 안내 → 결과 보고

## 신규 페이지 본문 템플릿

```markdown
# {YYYY-MM} 예산

## 예산
- 총 예산: 0원
- 카테고리별:
  - 식비: 0원 / 교통: 0원 / 문화: 0원 / 의료: 0원 / 공과금: 0원 / 기타: 0원

## 카테고리별 합계
| 카테고리 | 사용 | 예산 | 잔액 |
|---|---:|---:|---:|

## 지출 내역
| 날짜 | 항목 | 금액 | 카테고리 | 결제 |
|---|---|---:|---|---|
```

## 카테고리 자동 추론

| 카테고리 | 키워드 |
|---|---|
| 식비 | 점심·저녁·아침·간식·카페·커피·디저트·빵·치킨·피자·배달·식재료·마트·편의점·식당·뷔페·술 |
| 교통 | 택시·버스·지하철·주유·기름·휘발유·통행료·주차·기차·KTX·항공·비행기 |
| 문화 | 영화·콘서트·뮤지컬·전시·공연·도서·책·구독·넷플릭스·멜론·게임·유튜브 |
| 의료 | 약·약국·병원·진료·검진·치과·안과·정형외과 |
| 공과금 | 통신·전기·수도·가스·관리비·인터넷·휴대폰 요금 |
| 의류·생활 | 옷·신발·가방·생활용품·세제·화장품·이미용 |

## 금액 파싱 룰

`5,000원→5000` / `5천→5000` / `오만원→50000` / `3.5만→35000` / `3만5천→35000` / `￦5000→5000` / `-5000→환불·취소` / `$5→환율 확인`
한글 숫자: 일1·이2·삼3·사4·오5·육6·칠7·팔8·구9·십10·백100·천1000·만10000

## 규칙

- 통화 기본 KRW, 출력은 천 단위 콤마.
- **중복 방지**: 같은 날·같은 항목·같은 금액이 24시간 내 존재하면 확인 후 진행.
- **다중 항목 자동 분리**: "점심 8천, 카페 5천, 책 2만" → 3개 entry.
- **조회 모드**: "보여줘/확인/얼마/잔액" → fetch만, update 금지.
- **예산 경고**: 카테고리 100% 초과 `🚨 카테고리 예산 초과` / 80% 도달 `⚠️ 예산 80% 도달` / 총액 100% `🚨 총 예산 초과`. 예산이 0원(미설정)이면 경고 생략.
